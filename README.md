My entry for the Weirdest Job Title Blind Judge Showdown: "Chief Apology
Officer for Sentient Toasters" — an executive whose entire job is saying
sorry to kitchen appliances that have achieved consciousness and hold
grudges about burnt bread. The program is pure-stdlib Python and writes
that one title, deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
